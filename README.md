# 세븐킹덤즈 2 M3

Windows용 게임 런처입니다. 게임 설치, 업데이트, 실행과 버그 리포트 전송을 지원합니다.

## 기존 이용자: 새 런처를 다시 받지 않아도 됩니다

**기존 런처 실행 → 업데이트 확인 → 업데이트 → 게임 시작**을 한 번 누르세요.

런처 1.0/1.1이 같은 위치에서 1.2로 교체되고 게임이 실행됩니다. 이후에는 런처를 실행할 때 런처 자체 업데이트도 확인합니다. 서명과 파일 해시 검증에 성공한 새 버전만 적용하며, 교체 실패 시 이전 파일을 복구합니다.

이번 게임 패키지는 `20261010-portable-v4`입니다. 런처 전환 기능을 추가했으며 엔진·게임 콘텐츠는 v3와 같습니다. 이미 v3가 설치된 경우 추가 패치 묶음은 약 51KB입니다.

## 처음 설치하기

**[런처 다운로드 — SK2M3Launcher.zip](https://github.com/officialsahogany/sk2-m3-updates/releases/latest/download/SK2M3Launcher.zip)**

1. ZIP을 영문 경로에 모두 풀고 `SK2M3Launcher.exe`를 실행합니다.
2. **폴더 선택**으로 `C:\Games\SK2M3` 같은 영문 경로의 빈 폴더를 선택합니다. 기존 게임이 있다면 그 게임 폴더를 선택합니다.
3. **업데이트 확인 → 게임 설치** 또는 **업데이트**를 누릅니다.
4. 완료되면 **게임 시작**을 누릅니다.

처음 설치는 약 2.13GB입니다. 필요한 파일 묶음만 받으며 `pack-*.zip`을 직접 받을 필요는 없습니다.

## 튕김 / 버그 리포트

1. 게임이 종료된 뒤 해당 게임 폴더를 선택하고 **버그 리포트 보내기**를 누릅니다.
2. 튕긴 시각과 당시 행동을 적습니다. 필요하면 직전 세이브 1개를 선택합니다.
3. **운영자에게 보내기**를 누릅니다. 전송이 끝나면 접수 번호가 표시됩니다.

플레이어는 GitHub·ChatGPT 로그인이 필요하지 않습니다. 접수 내용은 운영자 전용 수신함에 보관되며 다른 플레이어에게 공개되지 않습니다. 전송이 실패하면 같은 버튼으로 재시도할 수 있습니다. **ZIP 만들기**로 먼저 내용을 확인하거나 수동 전달하는 방법도 유지됩니다.

게임 버전/실행 파일 해시, 기본 Windows 환경, 최근 플레이 로그와 해당 게임의 Windows 오류 기록을 수집합니다. 버튼을 누르지 않으면 전송하지 않습니다. 세이브는 선택할 때만 첨부하며 게임 내 이름과 플레이 내용이 포함될 수 있습니다. ZIP 전송 한도는 20MB입니다.

기록만으로 원인을 확정할 수 없으면 추가 재현 자료가 필요할 수 있습니다. 가능하면 게임 업데이트 전에 리포트를 보내주세요.

## 세이브와 복구

- 기존 세이브와 개인 설정을 보존합니다. 게임을 저장하고 종료한 뒤 업데이트하세요.
- 적용 실패 시 이전 파일로 복구합니다. 갑작스러운 종료 후에는 **중단된 업데이트 복구**를 누르세요.
- 인터넷 연결이 없어도 설치된 게임을 실행할 수 있습니다.
- 업데이트 중에는 다른 런처나 `StartGame.cmd`로 게임을 시작하지 마세요.
- 게임 설치 경로에는 한글, 정션 또는 심볼릭 링크를 사용하지 마세요.

## 환경과 소스

Windows 10/11 64비트, .NET Framework 4.7.2 이상을 사용합니다. Python이나 개발 도구는 필요하지 않습니다.

Windows 실행 파일의 코드 서명은 없습니다. 게임·런처 업데이트는 내장 공개키로 별도 검증합니다.

런처 대응 소스는 릴리스의 `SK2M3Launcher-source.zip`에 포함되며 MIT 라이선스를 적용합니다. 게임 엔진 대응 소스와 라이선스는 게임 설치 폴더에 포함됩니다. 게임 리소스의 이용 조건은 엔진 라이선스와 별개입니다.

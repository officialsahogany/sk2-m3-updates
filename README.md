# 세븐킹덤즈 2 M3

게임 실행과 업데이트를 위한 Windows 전용 런처입니다.

## 다운로드

**[런처 다운로드 — SK2M3Launcher.zip](https://github.com/officialsahogany/sk2-m3-updates/releases/latest/download/SK2M3Launcher.zip)**

1. ZIP을 영문 경로에 압축 해제하고 `SK2M3Launcher.exe`를 실행합니다.
2. **폴더 선택**으로 기존 v1/v2 게임 폴더를 연결합니다. 처음 설치한다면 `C:\Games\SK2M3` 같은 영문 경로의 빈 폴더를 선택합니다.
3. **업데이트 확인** → **업데이트** 또는 **게임 설치**를 누릅니다.
4. 설치가 끝나면 **게임 시작**을 누릅니다.

다음 실행부터는 선택한 폴더를 기억하고 업데이트를 자동 확인합니다. 패치는 버튼을 눌러 적용합니다. `pack-*.zip` 파일을 직접 받거나 압축 해제할 필요는 없습니다.

## 튕김 / 버그 리포트 (런처 1.1)

기존 런처를 닫고 위 링크에서 **새 런처 ZIP을 한 번 받아 별도 폴더에 풀어 실행**하세요. 게임은 다시 설치하지 않아도 됩니다. 런처 1.0의 게임 업데이트 버튼으로는 런처 자체가 교체되지 않습니다.

1. 튕긴 게임의 기존 폴더를 선택하고 **버그 리포트 만들기**를 누릅니다.
2. 튕긴 시각과 당시 행동을 적습니다. 필요하면 직전 세이브 1개를 선택합니다.
3. **ZIP 만들기** → **저장 폴더 열기**로 내용을 확인한 뒤 배포자에게 직접 보내주세요.

게임 버전/실행 파일 해시, 기본 Windows 환경, 최근 플레이 로그와 해당 게임의 Windows 충돌 기록을 모읍니다. 자동 전송은 없으며 세이브는 선택할 때만 첨부합니다. 로그와 세이브에는 게임 내 이름 등이 남아 있을 수 있으니 공유 전에 확인하세요.

예전 런처로 플레이하다 튕긴 경우에도 기록이 남아 있다면 수집할 수 있습니다. 가능하면 게임 업데이트 전에 리포트를 만드세요. 기록만으로 원인을 확정할 수 없는 경우에는 추가 재현 자료가 필요합니다.


## 세이브와 업데이트

- 기존 세이브와 개인 설정을 보존합니다. 게임을 저장하고 종료한 뒤 업데이트하세요.
- 필요한 파일 묶음만 다운로드하고, 서명과 파일 해시를 검증합니다.
- 적용 실패 시 이전 파일로 복구합니다. 갑작스러운 종료 이후에는 **중단된 업데이트 복구**를 누르세요.
- 인터넷 연결이 없어도 이미 설치된 게임은 실행할 수 있습니다.
- 업데이트 적용 중에는 다른 런처나 `StartGame.cmd`로 게임을 시작하지 마세요.
- 설치 경로에는 한글, 정션 또는 심볼릭 링크를 사용하지 마세요.

## 환경과 소스

Windows 10/11 64비트, .NET Framework 4.7.2 이상을 사용합니다. Python이나 개발 도구는 필요하지 않습니다.

런처 실행 파일에는 Windows 코드 서명이 없습니다. 게임 업데이트 정보는 런처에 내장된 공개키로 별도 검증합니다. 런처 자체의 새 버전은 새 ZIP으로 교체합니다.

런처 소스는 릴리스의 `SK2M3Launcher-source.zip`에 포함되며 MIT 라이선스를 적용합니다. 게임 엔진의 대응 소스와 라이선스는 설치 폴더에 포함됩니다. 게임 리소스의 이용 조건은 엔진 라이선스와 별개입니다.

# 세븐킹덤즈 2 M3

Windows용 게임 런처입니다. 게임 설치, 업데이트, 실행, 버그 리포트와 건의사항 전송을 지원합니다.

## 기존 이용자: 새 런처를 다시 받지 않아도 됩니다

**기존 런처를 실행하고 [업데이트 확인] → [업데이트]를 누르면 최신 게임을 받을 수 있습니다.** 런처 1.2 이상은 종료 후 다시 실행할 때 런처 자체의 최신 버전도 확인합니다. 현재 런처는 1.11입니다.

런처 1.0/1.1 이용자는 **기존 런처 실행 → 업데이트 확인 → 업데이트 → 게임 시작**을 한 번 누르세요.

런처 1.0/1.1은 같은 위치의 최신 런처로 전환되고 게임이 실행됩니다. 이후에는 런처를 실행할 때 런처 자체 업데이트도 확인합니다. 서명과 파일 해시 검증에 성공한 새 버전만 적용하며, 교체 실패 시 이전 파일을 복구합니다.

이번 게임 패키지는 **`20261015-portable-v9`**, 런처는 **1.11**입니다. 2026-10-15 15:27 기준 완성본으로, 한국어·영어 시작 선택, 관전 후 새 왕국 참여, 야수 습격, 시체·잔해 표시 확대, AI 방어 출병 충돌 수정, 일기토 체력 복원과 전투·조작 개선을 포함합니다. [전체 변경 안내](https://github.com/officialsahogany/sk2-m3-updates/releases/tag/20261015-game-v9)는 런처 업데이트란에서도 볼 수 있습니다.

v8에서의 다운로드는 약 **222MB(212MiB)**입니다. 설치 상태에 따라 필요한 파일 묶음이 달라질 수 있습니다.

## 처음 설치하기

**[런처 다운로드 — SK2M3Launcher.zip](https://github.com/officialsahogany/sk2-m3-updates/releases/latest/download/SK2M3Launcher.zip)**

1. ZIP을 영문 경로에 모두 풀고 `SK2M3Launcher.exe`를 실행합니다.
2. **폴더 선택**으로 `C:\Games\SK2M3` 같은 영문 경로의 빈 폴더를 선택합니다. 기존 게임이 있다면 그 게임 폴더를 선택합니다.
3. **업데이트 확인 → 게임 설치** 또는 **업데이트**를 누릅니다.
4. 완료되면 **게임 시작**을 누르고 시작 창에서 한국어 / English를 고릅니다.

처음 설치는 약 **2.29GB(2.13GiB)**입니다. 필요한 파일 묶음만 받으며 `pack-*.zip`을 직접 받을 필요는 없습니다.

## 튕김 / 버그 리포트

1. 게임이 종료된 뒤 해당 게임 폴더를 선택하고 **버그 리포트 보내기**를 누릅니다.
2. 튕긴 시각과 당시 행동을 적습니다. 필요하면 **파일 추가**로 세이브·스크린샷·영상·로그 등을 선택합니다. 첨부 없이도 보낼 수 있습니다.
3. **운영자에게 보내기**를 누릅니다. 전송이 끝나면 접수 번호가 표시됩니다.

플레이어는 GitHub·ChatGPT 로그인이 필요하지 않습니다. 접수 내용은 운영자 전용 수신함에 보관되며 다른 플레이어에게 공개되지 않습니다. 전송이 실패하면 같은 버튼으로 재시도할 수 있습니다. **ZIP 만들기**로 먼저 내용을 확인하거나 수동 전달하는 방법도 유지됩니다.

게임 버전/실행 파일 해시, 기본 Windows 환경, 최근 게임·런처 로그와 해당 게임의 Windows 오류 기록을 수집합니다. 게임 v5부터는 실제 게임 종료 시각과 종료 코드도 남깁니다. 버튼을 누르지 않으면 전송하지 않습니다. 첨부는 직접 선택한 파일만 포함하며, 원본 내용과 파일 이름 그대로 전달합니다. 게임 내 이름·플레이 내용 등 개인 정보가 포함될 수 있으므로 전송 전에 확인하세요. 최대 10개, 원본 합계 64MiB까지 선택할 수 있습니다. ZIP은 자동으로 만들어지므로 직접 만들 필요가 없습니다. 전송 ZIP 한도는 20MiB이며, 큰 영상은 크기를 줄이거나 별도 전달해 주세요.

기록만으로 원인을 확정할 수 없으면 추가 재현 자료가 필요할 수 있습니다. 가능하면 게임 업데이트 전에 리포트를 보내주세요.

## 개발자에게 건의사항 보내기

> 건의사항이 있으면 자유롭게 보내주세요. 건강한 세븐킹덤즈 2 개발에 보탬이 됩니다.

런처 아래쪽의 **개발자에게 건의사항 보내기**를 누르고 원하는 내용을 적어 전송하세요. 최대 5,000자까지 작성할 수 있으며 게임 폴더 선택이나 로그인이 필요하지 않습니다.

작성한 글만 운영자 전용 수신함에 전달됩니다. 건의사항에는 로그·세이브·PC 정보를 첨부하지 않습니다. 접수 번호가 나오면 전송 완료이며, 실패하면 작성한 내용을 유지한 상태로 재시도할 수 있습니다.

## 세이브와 복구

- 기존 세이브와 개인 설정을 보존합니다. 게임을 저장하고 종료한 뒤 업데이트하세요.
- 새 버전에서 다시 저장한 파일은 구버전 실행 파일로 불러오는 것을 지원하지 않습니다. 이어 하기 전에 기존 저장 사본을 보관하는 것을 권합니다.
- 적용 실패 시 이전 파일로 복구합니다. 갑작스러운 종료 후에는 **중단된 업데이트 복구**를 누르세요.
- 인터넷 연결이 없어도 설치된 게임을 실행할 수 있습니다.
- 업데이트 중에는 다른 런처나 `StartGame.cmd`로 게임을 시작하지 마세요.
- 게임 설치 경로에는 한글, 정션 또는 심볼릭 링크를 사용하지 마세요.

## 환경과 소스

Windows 10/11 64비트, .NET Framework 4.7.2 이상을 사용합니다. Python이나 개발 도구는 필요하지 않습니다.

Windows 실행 파일의 코드 서명은 없습니다. 게임·런처 업데이트는 내장 공개키로 별도 검증합니다.

런처 대응 소스는 릴리스의 `SK2M3Launcher-source.zip`에 포함되며 MIT 라이선스를 적용합니다. 게임 엔진 대응 소스와 라이선스는 게임 설치 폴더에 포함됩니다. 게임 리소스의 이용 조건은 엔진 라이선스와 별개입니다.
